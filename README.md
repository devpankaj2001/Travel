# Travel - Enterprise Activity Booking Platform

Enterprise Activity Booking Platform built with Next.js (Frontend) and Node.js / Express / MySQL (Backend).

## Repository Structure
- `backend/`: Express.js API, RBAC, MySQL Migrations & Database seeds
- `frontend/`: Next.js 14 App Router, Tailwind CSS, Responsive UI & Portals
- `PHASE_1_SPRINT_PLAN.md`: System architecture and Sprint breakdown

## Quick Start
### Backend
```bash
cd backend
npm install
npm run db:setup
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
